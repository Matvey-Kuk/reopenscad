            Before you start
            
A hobby project, for demonstration only

          

        

        

          
ReOpenSCAD is a hobby project, published for demonstration purposes. It is provided as is, with no warranty and no liability of any kind.

          
Workspaces are not private. There is no login — the URL is the only key, so anyone holding the link can read and change your work.

          
This is not storage you can rely on. Workspaces are deleted automatically — after two weeks without an edit, and sooner than that whenever the server is holding more than it keeps. Opening or rendering a workspace does not keep it alive; only editing does. Keep your own copy of anything that matters.

          
Exported geometry is not checked for you. Verify it before you print or manufacture from it.
